TECNOINFO V3 — GAMER NEON • VERSÃO GRATUITA
================================

Incluído:
- Visual Gamer Neon renovado: azul elétrico, ciano e vermelho, brilhos suaves, animações e cartões destacados.
- Cabeçalho atualizado com a identidade “TecnoInfo Gamer Edition”.
- Catálogo e pesquisa de serviços por texto, categoria e cidade.
- Perfil em destaque "TecnoInfo Informática".
- Serviços de currículo, trabalhos escolares/formatação, manutenção e limpeza de computadores, orientação para localizar contas de água e luz.
- Configuração do WhatsApp e cidade do perfil.
- Formulário de anúncios com foto, categoria, descrição, cidade e WhatsApp.
- Botões de contato via WhatsApp.
- Cadastro e login demonstrativos, somente locais.
- Painel administrativo local simples para apagar anúncios deste aparelho.
- Base PWA instalável pelo navegador em HTTPS.

COMO TESTAR
Abra index.html em um navegador. Para instalação e funcionamento offline como PWA, publique os arquivos em um host HTTPS.

PUBLICAÇÃO GRATUITA NO ANDROID
1. Crie uma conta gratuita no GitHub.
2. Crie um repositório público chamado tecnoinfo.
3. Envie index.html, manifest.json, sw.js, icon-192.png e icon-512.png para a raiz.
4. Abra Settings > Pages. Em Build and deployment, selecione Deploy from a branch, branch main e pasta /(root), e salve.
5. Aguarde o link HTTPS do GitHub Pages.
6. Abra o link no Chrome Android e escolha "Instalar app" ou "Adicionar à tela inicial".

LIMITAÇÕES IMPORTANTES
- Login e senha são demonstração local; não use senha real ou reutilizada. A senha fica armazenada localmente e não é adequada para produção.
- Anúncios, fotos e contas ficam apenas no aparelho/navegador atual; não sincronizam entre usuários.
- O painel administrativo local não tem proteção real e não deve ser usado como sistema administrativo público.
- Para contas seguras e anúncios compartilhados, conecte um backend gratuito (por exemplo Supabase ou Firebase), configure autenticação, banco de dados, armazenamento de fotos e regras de acesso. Isso exige configuração de projeto/chaves e testes de segurança.
- Este pacote é um aplicativo web instalável (PWA), não um APK nativo pronto para a Play Store.
- Ao ajudar com contas de água e luz, não peça nem armazene senha, código de barras ou dados bancários do cliente; oriente o pagamento nos canais oficiais.
- Trabalhos escolares devem ser apoio à digitação, formatação, revisão e orientação de estudo, sem prometer fazer atividades avaliativas em nome do estudante.
